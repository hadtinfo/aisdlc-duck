# Song ngữ EN/VI — Đợt 5b (dọn code và E2E tiếng Anh) Implementation Plan

**Goal:** `TestNoBareVietnamese` áp dụng toàn repo, không còn allowlist theo file; dọn các việc còn lại từ review
(mã lỗi "không ở chế độ web", chỉ dẫn feedback theo locale của repo, `spec.BoundaryTags`, chặn dot-import i18n ở web);
E2E có một lượt luồng nhẹ FIX-2 trên repo `locale: en` và kiểm web trả UI tiếng Anh khi người dùng chọn `en`.

**Architecture:**
- Scanner bỏ `testdata/bare-vietnamese-allow.txt`, cờ `-update-allowlist`, `waveOf`. Literal tiếng Việt là dữ liệu
  (bảng tiêu đề mục song ngữ, regex nhận cả hai ngôn ngữ) được miễn từng dòng bằng comment `// i18n:data <lý do>`:
  cuối chính dòng đó, hoặc một dòng comment riêng ngay trên. Marker không có lý do thì test báo lỗi; marker không
  miễn literal nào cũng báo lỗi (thừa). Self-test của scanner phủ các trường hợp này.
- Chỗ nào bỏ được literal thì bỏ: so khớp bằng `i18n.VI.T(...)`/`i18n.EN.T(...)` (khóa literal, đã có trong catalog);
  helper test `webtest` dùng câu `t.Fatalf` tiếng Anh.
- 409 "không ở chế độ web": `httpx.Error` có `Code`; `Fail` ghi `{"error": …, "code": "NOT_WEB_MODE"}` khi có mã.
  CLI so mã trước, câu (vi/en) là đường lùi cho server cũ.
- Chỉ dẫn feedback: `LocalizeFeedback` chuyển sang `internal/snapshot` (CLI và web cùng dùng); web giữ nguyên hành vi;
  CLI dịch `Instruction.Text` theo locale của repo trước khi giao agent (`policy.InstructionContext`). Phần ghi chú của
  người duyệt giữ nguyên văn.
- `review/docfacts.go` dựng regex thẻ biên từ `spec.BoundaryTags`.
- Guard web: dot-import `aisdlc/internal/i18n` dưới `internal/web`/`cmd/aisdlc-web` bị báo; self-test.
- E2E: repo `en-service` (bản sao fixture, `locale: en`, chính sách rủi ro tiếng Anh), FIX-2 init → cases → S1 →
  eval → review → eval --ci; mọi output CLI và `eval/report.md` không có ký tự tiếng Việt. Playwright `web-locale.mjs`:
  đăng nhập, `PUT /api/me/locale` `en`, kiểm nhãn tiếng Anh; đặt lại `vi`.

**Global Constraints:** locale vi giữ nguyên byte/kỳ vọng; không làm yếu test sẵn có; không sửa `plugin/**`, `docs/**`
(trừ file plan này), `README*`, `CHANGELOG.md`; không dependency mới.

**Review Focus:** marker chỉ miễn đúng dòng của nó; literal tiếng Việt mới ở bất kỳ file nào làm test fail; mã lỗi
không đổi JSON cũ ngoài trường `code` thêm vào; dịch chỉ dẫn không đụng ghi chú tự do.

## Tasks

1. **Bỏ allowlist** — `internal/i18n/catalog_test.go` (marker `i18n:data`, self-test), xóa
   `internal/i18n/testdata/bare-vietnamese-allow.txt`; `internal/spec/sections.go`, `internal/webclient/feedback.go`,
   `internal/cli/servertext.go`, `internal/web/webtest/*.go`. Kiểm: `go test ./internal/i18n`.
2. **Mã NOT_WEB_MODE** — `internal/web/httpx/locale.go`, `internal/web/gates/{service,imports}.go`,
   `internal/cli/{servertext,webgates}.go`; test httpx, CLI (mã, câu en, câu vi), IT gates kiểm `code`.
3. **Chỉ dẫn feedback theo locale repo** — `internal/snapshot/feedbacktext.go`, `internal/web/gates/feedbacktext.go`,
   `internal/policy/hook.go`; test snapshot + policy (en dịch, ghi chú giữ nguyên, vi không đổi).
4. **BoundaryTags** — `internal/review/docfacts.go` dùng `spec.BoundaryTags`; test sẵn có giữ nguyên.
5. **Guard dot-import** — `internal/i18n/catalog_test.go`.
6. **E2E tiếng Anh** — `e2e/run-e2e.sh`, `e2e/solutions/FIX-2-en/*`, `e2e/web-locale.mjs`. Kiểm: `make e2e`.
7. **Kiểm tra cuối** — `gofmt -l .`, `go vet ./...`, `AISDLC_SKIP_DOCKER=1 go test -race ./...`, test web Docker,
   `make e2e`.
